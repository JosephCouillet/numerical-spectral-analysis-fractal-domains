# Numerical Spectral Analysis on Fractal Domains

Academic research project — CentraleSupélec, Department of Applied Mathematics (2025).

## Overview

This project investigates eigenmode localization in pre-fractal domains through numerical spectral analysis of the Neumann Laplacian.

The study explores how increasing boundary complexity influences the spatial distribution of eigenfunctions and leads to energy localization.
